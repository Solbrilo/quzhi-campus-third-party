# 与 muguang 的功能对比

对比日期：2026-11-08。muguang 以公开 `main` 的
[`abd2f95`](https://github.com/Ranxian/muguang/tree/abd2f95f62d2724111fa3f7999aa793363dd2ac1)
源码和 README 为依据；本应用以当前 Android 源码为依据。下表描述源码提供的能力，未使用真实学校账号验证对方应用。

| 功能 | muguang | 本应用 Android |
| --- | --- | --- |
| 充值 | 独立充值页，查询学校套餐与通道，通过支付宝 SDK 付款；还实现聚合收银台和校园卡跳转，是否可用取决于学校 | 原来打开支付宝趣智校园小程序；本次改为半屏选金额、创建学校订单、直接调用支付宝 SDK，返回后查询余额 |
| 热水控制 | 同时实现云端 TCP 设备控制与真正的 BLE/GATT 蓝牙水表控制 | 使用 HTTPS 云端热水控制；BLE 用于发现设备并绑定，尚无 GATT 开关阀通道 |
| 洗衣机 | 内测，可同时绑定两台，选择模式并查看各自状态和剩余时间 | 暂无洗衣机功能 |
| 自动结束用水 | README 声明按剩余金额或时长自动结算，源码含独立的用水安全策略 | 当前侧重开关水、计时、服务端自动关水恢复与延迟结算，没有对应的用户预算设置 |
| 账单与统计 | 消费分类、消费趋势、项目隔离；未支付账单列表及手动补扣 | 月度/年度筛选、费用与用水量汇总、使用记录、待结算同步；暂无趋势图和手动代扣入口 |
| 账号与项目 | 项目切换、账户/学校信息、一卡通余额、换手机号、重设密码、使用码等入口 | 密码/短信登录、账号状态恢复、配置导入导出及设备切换；新增用户名与学校、修改密码和更换手机号；仍无项目切换与校园卡管理入口 |
| 外观 | 默认、极简、暖纸、终端四种风格；自定义图片背景、配色和卡片调整 | 七套预设与自定义图片/配色/圆角/动画、手机外壳预览、深浅色、玻璃强度与统一过渡 |
| 小组件 | 1×1、2×2、2×4，可直接启停；具备洗衣机相关状态 | 热水状态与启停小组件、新增 2×1 横向开关；另有系统快捷设置磁贴 |
| 消息与反馈 | 主要聚焦设备、钱包、账号及设备状态通知 | 校园消息列表、已读状态与详情，内置问题反馈、通知与震动设置、实况通知 |
| 平台范围 | 当前公开仓库为 Android | 项目另有 HarmonyOS 客户端；本次改动只涉及 Android |

4.0.0 已补齐账户信息、换号、两种密码修改方式、图片背景和主题定制，并加入系统公告与私有管理台。仍未引入洗衣机、蓝牙开阀、项目切换或代扣业务。

## 4.0.0 后值得优先优化的内容

1. **用水预算与时长提醒**：先加入余额不足、长时间用水的提醒和明确关水入口；自动关阀需要继续保持订单身份、网络失败恢复和结算确认。
2. **待支付账单入口**：先提供未支付状态与解释，再在有真实服务验证后开放手动补扣；不能自动代扣或重试扣款。
3. **消费趋势**：在现有按月/按年筛选上补充费用与用水量趋势，缺失数据明确标记，避免把未同步账单当作零消费。
4. **学校项目切换**：为多校区用户提供服务端项目列表，同时隔离余额、账单、设备和订单；当前配置导入不等同于完整项目切换。
5. **支付通道适配**：当学校不支持支付宝直接充值时，可进一步接入官方聚合收银台或校园卡入口，保留清晰的失败原因。
6. **设备能力识别**：BLE/GATT 直接开阀和洗衣机值得作为独立迭代；必须按设备协议和真机验证，不能仅将附近设备扫描当作可控制证明。

这次已采用的逻辑改进：换号验证码发往新手机号、为短信注册用户提供验证码改密、账户变更前阻止未结束用水/未同步账单、非幂等账户和支付请求不自动重试、自定义图片本机存储和公告回复按版本去重。
