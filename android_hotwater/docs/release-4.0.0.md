# Android 4.0.0

源码版本 `4.0.0 (31)`，应用 ID 和既有 Release 签名不变。此文件记录构建内容，不代表已经创建 Gitee Release 或推送 Git 标签。

- 设置顶部改为账户卡片，提供用户名、学校、登录状态、换手机号和密码修改；密码修改支持原密码或短信验证。
- 应用信息、更新日志、配置和项目链接移入“关于应用”半屏页面。开源支持补齐运行库与开发套件，网站使用 Nebularive 图标。
- 主题页提供手机外壳预览；七套预设后新增自定义图片背景、位置、模糊、背景色、主题色、圆角和热水开关动画。编辑时上方保留完整预览，下方独立滚动，支持色轮与明度选色、在预览中拖动缩放图片、实时模糊与自动提取图片底色。
- 充值面板关闭时向下降出；开水成功后连接状态显示蓝色“正在使用”。
- 消息可筛选校园消息、系统公告或全部。公告支持定时、生效期和选择/自由输入回复。
- 网站私有管理台显示日活、月活、版本分布以及公告编辑与回复汇总，并支持按月份、平台、类型查看应用反馈。统计接口兼容旧版本，版本字段为可选增量。
- 消息来源与账单筛选共用一致的主题化菜单。
- 首次安装与更新后恢复欢迎页：居中竖排“至繁归于至简”按“至繁”“归于至简”分两段显现。升级后提供四页半屏功能展示，完成后同版本不再重复；旧 4.0.0 安装在首次更新此欢迎体验时补展示一次。
- 每段中文入场时震动一次，遵循应用震动开关；英文格言移入关于应用。四页介绍是新主题、自定义主题、小组件与充值，附实际界面截图，最后按钮为“太棒啦！”，关于应用提供“查看新功能”。
- 子页面独立背景和触摸区域；滚动卡片上缘保留圆角，标题随内容折叠后退出。主页面使用连续跟手分页，底栏指示同步移动。
- 2×1 / 2×2 小组件重新设计为拟真滑块，采用白色/深色外圈与四色状态灯；2×2 显示状态胶囊和余额。按可见状态去重更新并复用视图，避免无变化的后台刷新反复重建。主页同步状态胶囊并移除宿舍位置行。

公告在应用启动/回到前台及前台每分钟同步；应用关闭时不保证按指定时间唤醒。账户变更、真实支付、设备开关阀与 OEM 通知行为仍需学校账号和真机验证。

管理服务部署和维护见 `server/hotwater-activity/README.md`。认证密码与运行数据不在仓库中。

### 3×2、3×3 组件与即时切页触觉

3×2、3×3 和其他具有足够高度的经典小组件统一使用 2×3 的布局：状态在左上，信息在中部，开关水按钮在底部。3×2 高度有限时收起次要说明，保留主要状态与操作；窄网格下的 3×2 也不会误用拟物滑块。

滑动切页的触觉跟随 Pager.currentPage（与底栏选中项一致），在页面跨过切换位置时触发，不再等待 settledPage 或惯性动画停止；页面反向切回时也及时反馈，动画结束不追加震动。底栏点击原有反馈及应用震动开关继续生效。

本次定向检查：3 项尺寸选择单测通过；3 项模拟器测试通过，覆盖八种尺寸的状态/按钮位置、手指松开前的切页触觉以及底栏点击去重。小组件的主体文字与按钮无重叠。测试结束后已停止模拟器，C 盘未发现本轮新增的项目临时文件或崩溃转储。
